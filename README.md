# Unreal Engine 5 VFX Cookbook — Intro Video


This folder contains the introductory companion video for Packt's *Unreal Engine 5 VFX Cookbook* by Hussin Khan.


The video explains how to open the downloadable Unreal Engine project and find the chapter-based levels, assets, and Niagara systems used while following the book's recipes.

## Before you begin


Install Unreal Engine 5.6.1 through the Epic Games Launcher. The interface, settings, project behavior, or final visual effects may differ if the project is opened in another engine version.


Download and fully extract the accompanying project archive before opening it. Keep the `Config` and `Content` folders together with the `.uproject` file.


## Quick start


1. Open the extracted project folder.
2. Double-click the `VFX_COOKBOOK.uproject` file.
3. If Unreal Engine asks which version to use, select **5.6.1**.
4. Allow a minute or two for the first launch. Asset discovery and shader preparation can make the initial load slower than later sessions.
5. Use the Content Browser to open the level or asset folder that corresponds to the chapter and recipe you are following.


## Finding the project content


The project is arranged to make the book's examples easier to locate:


- `Content/Levels` contains the supplied levels, organized around the book chapters.
- `Content/Niagara_Systems` contains chapter-related Niagara effects and systems.
- Other top-level folders group supporting content such as animations, Blueprints, characters, materials, meshes, sequences, textures, and third-party assets.
- The VFX sandbox level provides a general workspace for previewing and testing effects.


Folder names and available assets may vary slightly between project releases. If an item is not immediately visible, use the Content Browser search and check the folder for the relevant chapter.


## Troubleshooting


### The project does not open


- Confirm that the archive was completely extracted.
- Check that the `.uproject` file remains beside the `Config` and `Content` folders.
- Confirm that Unreal Engine 5.6.1 is installed.


### The first launch appears slow


Allow Unreal Engine time to discover assets and prepare shaders. This is normal on the first launch and depends on the computer and project cache.


### The editor looks different from the video


Verify the engine version. The walkthrough was recorded with Unreal Engine 5.6.1; later or earlier releases may change menus, panels, defaults, and rendering results.


### I cannot find the example for a recipe


Start in `Content/Levels` for chapter levels and `Content/Niagara_Systems` for Niagara effects. Match the chapter number to the recipe, or search by the effect or asset name in the Content Browser.
